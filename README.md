# ChatUp 💬

Chat en tiempo real con mensajes directos y grupos.

## Features

- Mensajes directos y grupales en tiempo real
- Autenticación JWT
- Notificaciones de sonido
- Persistencia de mensajes
- UI responsive (mobile + desktop)

## Stack

| Frontend | Backend |
|----------|---------|
| React + TypeScript | Bun + Express |
| Vite | WebSockets |
| Tailwind CSS | PostgreSQL |

## Correr local

# Clonar
git clone https://github.com/TU_USUARIO/chatup

# Backend
cd server
bun install
bun dev

# Frontend
cd client
bun install
bun dev
